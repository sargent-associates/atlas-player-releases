# Atlas Player

Atlas Player is a signed and notarized macOS menu bar companion for Atlas and Apple Music.

## Install

1. Download [Atlas-Player.dmg](https://github.com/sargent-associates/atlas-player-releases/releases/latest/download/Atlas-Player.dmg).
2. Open the disk image and drag **Atlas Player** to **Applications**.
3. Launch Atlas Player from Applications and allow Music automation when macOS asks.

Atlas Player checks for signed updates automatically. You can also choose **Check for Updates…** in its footer.

This repository contains no application source. Release binaries, appcasts, and release notes are attached to [GitHub Releases](https://github.com/sargent-associates/atlas-player-releases/releases).
